# ADR 0006: 收件箱优先采集、侧边栏就地归档胶囊与批量整理系统架构

- **状态 (Status)**: 已采纳 (Accepted)
- **日期 (Date)**: 2026-09-18
- **决策者 (Deciders)**: 核心团队 & 用户
- **关联文档**: `CONTEXT.md`, `docs/adr/0005-google-identity-and-prompt-style-decoupling.md`

---

## 1. 背景与问题陈述 (Context & Problem Statement)

在扩展日常使用中，用户在图片素材的收集与归纳流程中遇到了以下严重影响心智模型的交互瓶颈：
1. **当前文件夹采集失焦盲区**：用户进入插件正停留在特定文件夹（如 `222`）时，在网页端看到图片并进行右键采集。由于新采集资产的 `folderId` 缺省为未分类，而侧边栏当前只展示 `folderId === 222` 的素材，导致采集成功后用户在当前列表完全看不到任何新素材，体验反直觉；
2. **采集时的文件夹预选诉求与阻断矛盾**：用户希望右键收集时能顺便选择归属文件夹，但若强加阻断式弹窗或多步操作，会大幅破坏高频连击采集时的流畅感；
3. **单卡片移动体验单一**：仅依赖长按卡片物理拖拽到侧边文件夹，在侧边栏狭长空间中极易发生手部疲劳与拖动误触，缺乏直接的卡片右键/快捷菜单移动方式；
4. **批量整理缺失**：缺乏多选能力，用户无法快速勾选多张素材进行统一归档、批量转移或批量清理。

---

## 2. 决策驱动因素 (Decision Drivers)

- **资产确定感与零污染 (Certainty & Cleanliness)**：避免采用“将新素材静默写入当前活跃文件夹”的黑盒策略，杜绝用户在不知情状态下造成的文件夹分类污染；
- **非打断式流转 (Non-Intrusive Flow)**：保持网页端与侧边栏高频采集零阻塞，通过动态浮动胶囊提供“秒存 + 随手可选”的低摩擦弹性交互；
- **移动方式双轨化**：同时支持“鼠标拖拽派”与“菜单点击派”，提供最直接的快捷归档；
- **批量操作效率**：在多选态下赋予整张卡片直觉的勾选切换行为，并支持聚合拖拽与统一移动。

---

## 3. 架构设计与技术方案 (Architectural Solutions)

### 3.1 收件箱优先原则与侧边栏就地归档胶囊 (Inbox-First & In-Context Filing Pill)
- **收件箱优先入库**：所有网页右键、截图与导入的新素材，初始统一作为未分类条目（`folderId: undefined`）入库，保证资产归属清晰一致。
- **侧边栏智能聚合胶囊**：
  - 当侧边栏处于特定文件夹（如 `selectedFolderId: 222`）且检测到新素材入库事件时，顶部滑出动态操作胶囊：
    `✨ 新采集 N 项素材至未分类 [全部移入 222] [查看]`；
  - 点击「全部移入」直接将这批素材更新至当前文件夹，利用 Dexie `useLiveQuery` 触发平滑高亮更新；
  - 若处于「全部素材」或「未分类」，则显示 1.5 秒淡出的极简微反馈 `✓ N 项素材已保存`。

### 3.2 网页端 Shadow DOM 悬浮归档胶囊 (Webpage Quick-Filing Capsule)
- 网页端右键采集依然为 1 击秒存，绝不打断浏览主线；
- 采集成功后，Content Script 通过原生 `attachShadow` 在网页右下角（`bottom: 24px, right: 24px`）渲染微型悬浮胶囊：
  `[图标] 已保存 [📁 默认未分类 ▾] [✕]`；
- 默认 3 秒静默淡出；若鼠标 Hover 或展开文件夹下拉选择时**暂停倒计时**；
- 用户点击下拉可即时切换目标文件夹，向 Background 发送更新指令。

### 3.3 单卡片快捷菜单与就近 Popover (Card Action Menu)
- 卡片右上角悬浮 `...` 更多按钮，且卡片全局支持右键原生上下文拦截（`onContextMenu`）；
- 呼出就近定位的轻量 Popover 悬浮浮层，展示层级文件夹列表与搜索栏，点击目标文件夹直接就地转移，彻底规避狭窄侧边栏横向二级级联菜单超屏被裁切的硬伤。

### 3.4 批量整理模式 (Batch Selection Mode)
- **多入口激活**：卡片 Hover 左上角圆圈复选框点击激活，或顶部 Header「批量选择」按钮激活；
- **全卡响应**：多选态下点击卡片任意区域均直接切换选中/反选状态，极大解放鼠标点击负担；
- **底部悬浮批量栏**：显示已选数量、全选/反选、批量移动至（Popover 树）、批量删除（带二次确认）；
- **聚合拖拽增强**：多选态下按住任一已选卡片拖动，自动生成多卡聚合条状胶囊（`已选 N 项素材 ▤`），拖进 `FolderNav` 任何目标文件夹即可一并转移。

---

## 4. 影响与收益评估 (Consequences)

### 正向影响 (Positive)
- **彻底根治反直觉黑盒**：用户清楚了解素材先进入收件箱，且能随时一键追加到正在浏览的文件夹；
- **高频采集体验丝滑**：网页端既能盲采，又能随手通过 3 秒胶囊完成改配；
- **大规模资产整理效率提升**：告别单张死板拖拽，多选批量移动使素材归类效率提升数倍。
