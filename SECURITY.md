# Security policy

## Reporting a vulnerability / 报告漏洞

Please **do not** open a public issue for security problems.

Email **support@picpocket.top** with the subject `[SECURITY] <short summary>` and include:

- what is affected (extension version, page, or the hosted service),
- steps to reproduce or a proof of concept,
- the impact you expect.

请**不要**在公开 Issue 中披露安全问题。请发邮件到 **support@picpocket.top**，标题以 `[SECURITY]` 开头，
并说明受影响范围（扩展版本、页面或托管服务）、复现步骤和预期影响。

We aim to acknowledge reports within 3 business days and to keep you updated until the issue is resolved.
Please give us reasonable time to fix a problem before disclosing it publicly.

## Scope / 范围

- The PicPocket Chrome extension and the code in this repository.
- The website `picpocket.top` and the hosted service used by the extension (accounts, credits, payments).

Secrets (API keys, payment keys, service credentials) must never be committed to this repository. If you find one,
report it as a security issue.

## Supported versions / 支持的版本

Security fixes are made on the latest release only.
