Add it in one click. 一键添加，装好就能用。

PicPocket is on the Chrome Web Store, and Chrome keeps it up to date for you. PicPocket 已上架 Chrome 应用商店，之后由 Chrome 自动更新。

Add to Chrome 添加到 Chrome

Or build from source. You'll need Git and Bun. 也可以从源码构建，需要先安装 Git 和 Bun。

Get the code获取代码

Clone the repository, or download it as a ZIP from GitHub.克隆仓库，或在 GitHub 上下载 ZIP 压缩包。

$ git clone https://github.com/QingYunA/picpocket.git

Build the extension构建扩展

Install dependencies and build. The output goes to dist/chrome-mv3.安装依赖并构建，产物会生成在 dist/chrome-mv3。

$ cd picpocket
$ bun install
$ bun run build

Load it in Chrome加载到 Chrome

Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the dist/chrome-mv3 folder.打开 chrome://extensions，开启右上角开发者模式，点击加载已解压的扩展程序，选择 dist/chrome-mv3 文件夹。

→ chrome://extensions

To update a source build, run git pull and bun run build, then click the reload icon on PicPocket's card in chrome://extensions. 源码版更新：执行 git pull 与 bun run build，再到 chrome://extensions 中点击 PicPocket 卡片上的刷新按钮。

Your pocket stays on your machine. 你的口袋，只留在你的电脑里。

PicPocket has no media server. What you save lives in your browser, and you can delete it any time. PicPocket 没有图床服务器。你收藏的一切都保存在自己的浏览器里，随时可以删除。

  • Stored in your browser保存在你的浏览器里Images, prompts, tags and notes are kept in local IndexedDB.图片、提示词、标签和笔记都保存在本地 IndexedDB。
  • Your key, your provider你的 Key，你选的服务商Your API key is kept locally and sent only to the endpoint you configure.API Key 保存在本地，只发送到你自己配置的接口地址。
  • No tracking没有追踪No analytics SDKs in the extension, no browsing history, no selling data.扩展不集成分析 SDK，不记录浏览历史，不出售任何数据。

Questions, answered. 常见问题

Something else? Email us. 还有其他问题？给我们写信。

Which AI models does it work with?支持哪些 AI 模型？
For reading images, any OpenAI-compatible vision model works, including providers like OpenAI, DeepSeek, SiliconFlow and StepFun, or a custom endpoint. The prompts it produces are plain text, so you can paste them into Midjourney, Flux, Stable Diffusion or any other image tool. 反推图片可以使用任意 OpenAI 兼容的视觉模型，例如 OpenAI、DeepSeek、硅基流动、阶跃星辰，或者自定义接口。生成的提示词是纯文本，可以粘贴到 Midjourney、Flux、Stable Diffusion 等任何生图工具。
Do I need an account?需要注册账号吗？
No. Install the extension, add your own API key in settings, and start capturing. Saving images to your pocket doesn't need a key at all. You only need to sign in for the monthly free credits or a paid plan. 不需要。安装扩展后在设置中填入自己的 API Key 即可开始使用。单纯收藏图片到口袋完全不需要 Key。只有领取每月免费积分或购买套餐时，才需要登录账号。
What does it cost?需要付费吗？
The extension is free. With your own key, you pay your AI provider directly for the requests you make. If you'd rather not manage keys, hosted models run on credits, and every account gets 30 free credits a month (see Pricing). Hosted requests go through PicPocket's server, as the privacy policy explains. 扩展本身免费。使用自己的 Key 时，调用费用直接由你和 AI 服务商结算。如果不想自己管理 Key，可以使用托管模型，按积分计费，每个账号每月赠送 30 积分，详见定价。托管请求会经过 PicPocket 的服务器，详见隐私政策。
Why does Chrome say it can “read and change data on all websites”?为什么 Chrome 提示它能“读取和更改所有网站上的数据”？
That's Chrome's standard wording for extensions that work on any site. PicPocket needs it so the hover pill and the right-click menu work wherever you find inspiration. It doesn't inject ads, change page content or log where you go. 这是 Chrome 对可在任意网站运行的扩展使用的标准提示。PicPocket 需要它，悬停胶囊和右键菜单才能在你浏览的任何网站上使用。它不会注入广告、篡改网页内容或记录你的浏览轨迹。
How do I delete my data?如何删除我的数据？
Delete any image, folder or prompt from the side panel. Uninstalling the extension removes everything it stored in your browser. 在侧边栏中可以随时删除任意图片、文件夹或提示词。卸载扩展时，浏览器会清除它保存的全部数据。
