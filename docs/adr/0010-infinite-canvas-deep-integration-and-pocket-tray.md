# 0010: 无限画布深度吸收与纯净台面资产抽屉架构

## 状态
已通过 (Accepted)

## 上下文与问题陈述
在第一阶段（ADR 0009）独立全屏无限画布工作台上线后，收到了深入的用户实战反馈与需求痛点：
1. **纯净台面与历史素材复用的结构性冲突 (Desk vs Warehouse)**：
   - 之前版本默认将 IndexedDB 中最近生成的历史图片全部自动平铺在画布上，导致视口极为臃肿；
   - 用户在制作具体任务（如“小红书封面”）时，需要一张干干净净的纯白或纯黑画纸，不被以往杂七杂八的历史图片干扰；
   - 与此同时，用户在构思创作时又极其需要能够**顺手看到口袋里以往存过什么素材**，并能丝滑拖拽上桌取用。
2. **纯暗黑界面与侧边栏的视觉割裂 (Theme Inconsistency)**：
   - 原工作台写死纯暗黑主题（`bg-zinc-950`），在白天或浅色系统偏好下与主扩展侧边栏风格割裂，缺少浅色模式与一键明暗切换。
3. **创作过程中的文字灵感与排版记录缺失**：
   - 缺少轻量文本便签节点，用户无法在画布空白处随手记录 Prompt 灵感碎片、构图备忘或文案排版注释。
4. **图片轻量二次加工链路过长**：
   - 生成或收集的图片如需微调尺寸比例、裁掉边缘黑边或修正旋转方向，不得不跳出扩展使用外部软件。

## 决策 (Decision)

我们基于开源项目 `basketikun/infinite-canvas`（MIT 协议）的核心设计精髓，结合用户反馈与 PicPocket 自身的产品定位，做出以下关键架构决策：

### 1. 纯净台面 vs 随叫随到的口袋抽屉架构 (Desktop vs Drawer)
- **画布即台面 (Canvas as Working RAM)**：
  - 画布视口默认保持极简纯净，不主动从数据库加载历史海量图片铺满屏幕；
  - 仅承载用户当前会话主动生成、主动拖入、或从抽屉挑选的活跃卡片。
- **口袋素材抽屉 (Pocket Drawer as Persistent Warehouse)**：
  - 左侧常驻轻量滑出抽屉 `[ 📦 我的素材 ]`（支持快捷键 `P` 开关）；
  - 直接读取 Dexie `db.items`（网页收集图与历史生成图），支持按文件夹（如“小红书封面”、“日常灵感”）快速检索与翻阅；
  - **原生拖拽上桌 (Drag & Drop)**：看中某张图片，鼠标长按拖拽至画布任意空白处即成为图片卡片节点；拖入生图控制台参考图槽位即成为垫图。
- **台面清理 (Clear Stage)**：
  - 顶栏提供 `[ 🧹 清空台面 ]` 动作，一键清空当前画纸所有卡片，底层数据库（`items` 与 `generationTasks`）数据只增不减、绝对零损失。
- **卡片入库归档**：
  - 台面上的图片卡片支持“存入图库”，并可直接选择目标文件夹。

### 2. 浅色与暗色双模主题引擎 (Dual-Theme Engine)
- 顶栏常驻 `☀️ / 🌙` 切换按钮，状态持久化于 `localStorage`（键名 `picpocket_canvas_theme`），默认随系统或用户偏好；
- **浅色模式设计规范**：
  - 背景：`bg-[#F8FAFC]`（Slate-50 象牙白），网格点阵：`rgba(100, 116, 139, 0.2)`；
  - 卡片与控制台：纯白底高质感立体阴影（`bg-white/95 border-slate-200/90 shadow-xl`）；
  - 顶栏与抽屉：白透毛玻璃（`bg-white/85 backdrop-blur-xl border-slate-200`）；
- **暗色模式设计规范**：
  - 沿用成熟的深空灰沉浸黑（`bg-zinc-950`，卡片 `bg-zinc-900/95 border-zinc-800`）。

### 3. Text 灵感便签节点 (CanvasTextCard)
- 吸收 Infinite Canvas 的便签插件（`sticky-note`）心智：
  - 支持双击画布空白处、或点击顶栏 `[ 📝 便签 ]`（快捷键 `T`）在视口中心生成便签卡片；
  - 支持多行文本自适应编写、实时保存、自由拖动与一键删除。

### 4. 纯本地轻量图片二次加工工具条 (In-situ Image Manipulation)
- 吸收 Infinite Canvas 的 `canvas-image-data.ts` Canvas 处理逻辑：
  - **自由裁切 (Crop)**：弹出轻量弹窗，支持 1:1、3:4、4:3、9:16、16:9 与自由拉伸，纯本地 Canvas 处理；
  - **旋转 (Rotate)**：点击顺时针旋转 90 度，毫秒级就地原地替换预览图；
  - **高清放大 (Upscale / 2x)**：采用高质量逐级插值放大（`drawStepUpscale`）；
- 0 外部依赖，0 破坏性篡改原图，支持另存新卡片。

### 5. 功能边界确认：排除整幅拼图快照导出
- 经过核对 `infinite-canvas` 源码，该项目仅有面向 MCP Agent 的 JSON 结构快照（`compactCanvasState`），并没有离屏渲染整幅 PNG 拼图快照的功能；
- 遵从用户“Infinite Canvas 如果没有就不要了”的指示，本阶段坚决不引入快照导出功能，保持工具精简克制。

## 后果 (Consequences)

### 正向影响
- 完美化解了“纯净创作”与“资产复用”之间的矛盾，给创作者带来无干扰的呼吸感台面；
- 浅色与暗色模式满足不同采光环境与个人审美诉求；
- 本地 Canvas 裁切、旋转与便签大幅缩减了创作迭代链路，无需频繁切出切入其他软件。

### 潜在代价与注意事项
- 抽屉需要对多图缩略图进行高效轻量化渲染，防止大图库一次性挂载过多 DOM。
