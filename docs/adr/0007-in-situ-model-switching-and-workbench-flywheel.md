# ADR 0007: 就地模型即时切换、多参考图托盘与生图飞轮闭环架构

- **状态 (Status)**: 已采纳 (Accepted)
- **日期 (Date)**: 2026-09-19
- **决策者 (Deciders)**: 核心团队 & 用户
- **关联文档**: `CONTEXT.md`, `docs/adr/0004-image-generation-workbench-and-asset-flywheel.md`, `docs/adr/0005-google-identity-and-prompt-style-decoupling.md`

---

## 1. 背景与问题陈述 (Context & Problem Statement)

随着用户自带 API 凭据（BYOK）接入第三方中转服务（如 OneAPI、NewAPI、硅基流动等聚合平台），单一 Base URL 下往往挂载着数十款不同的视觉多模态反推模型与文生图模型。原有扩展架构存在以下严重脱离创作心智的瓶颈：
1. **模型切换路径极深且反常态**：生图工作台与我的口袋反推抽屉均仅展示静态模型名称，用户若想换一个模型试效果，必须手动点击右上角进入“设置弹窗”，翻找对应选项修改保存后退出，流程割裂；
2. **生图交互参数维度薄弱**：仅有 5 个写死的画幅比例，缺少画质分级（Quality）、扩展流行比例（如 21:9 超宽屏、2:3 经典海报竖图）及多图批次控制；
3. **缺乏以图生图与迭代闭环**：参考图仅支持单图被动带入，无法在工作台内直接从剪贴板粘贴、本地多图拖拽或批量上传；且生成的新图片无法直接反哺为下一轮生成的参考图（缺失以图生图迭代能力）；
4. **与开源标杆 Infinite Canvas 的体验差距**：未能吸收 Infinite Canvas 在生图工作台上直观的 `ModelPicker` 胶囊、多参考图灵活编排与产物飞轮的核心设计。

---

## 2. 决策驱动因素 (Decision Drivers)

- **就地即时掌控 (In-Situ Control)**：杜绝跨页面切换模型，在工作台与反推抽屉的核心视野区直接提供即点即切的模型胶囊；
- **BYOK 聚合模型高密度适配**：针对一个 Key 挂载海量模型的场景，提供即时模糊搜索、一键从当前 Base URL 拉取 `/models`，以及官方预设一键选择；
- **即切即用与静默持久化**：用户在工作台/抽屉切换模型不仅即时生效，同时自动回写至 `UserSettings`，保持后续默认创作习惯的一致性；
- **生图创作飞轮 (Creation Flywheel)**：形成“采集 ➔ 视觉反推 ➔ 提示词入工作台 ➔ 生图 ➔ 结果图一键转为参考图继续垫图迭代 ➔ 沉淀至素材库”的完整生命周期。

---

## 3. 架构设计与技术方案 (Architectural Solutions)

### 3.1 紧凑型就地模型选择胶囊 (`InlineModelPicker.tsx`)
- **视觉形态**：高度 28px~32px 的胶囊按钮，展示当前厂商官方品牌矢量图标（来自 `@iconify/react` 与 `@lobehub/icons`）+ 模型名称 + 展开小箭头；
- **能力区隔 (`capability: 'image' | 'vision'`)**：
  - 生图工作台绑定 `capability="image"`，默认列出 `presetModels.json` 中的生图旗舰（FLUX.1 schnell/dev, DALL-E 3, Grok-Imagine, CogView-4, Wanx 2.1 等）；
  - 反推抽屉绑定 `capability="vision"`，默认列出视觉反推旗舰（MiMo v2.5, Qwen2.5-VL, Janus-Pro, DeepSeek, GLM-4V, GPT-4o 等）；
- **Popover 弹出式浮层**：
  - **搜索栏**：实时过滤本地与已拉取的模型名称；
  - **动态获取**：点击「刷新可用模型」，向当前 Base URL 发起 `GET /models`，平滑解析并在浮层中供用户挑选；
  - **自由输入**：任何私有或中转特有模型名称，回车即可应用；
- **持久化回写**：选择后同步更新全局 `settings.imageModel` 或 `settings.model`，触发 Chrome Storage 与 Dexie 状态更新。

### 3.2 多参考图托盘系统 (`Multi-Reference Tray`)
- **多输入通路**：
  1. **剪贴板一键粘贴**：点击「从剪贴板粘贴」或在工作台激活时 `Ctrl/Cmd+V` 监听，直接将复制的图片载入托盘；
  2. **拖拽投掷区**：支持将网页图片或本地桌面图片直接拖入虚线托盘；
  3. **文件选择器**：支持多选图片批量载入；
- **托盘编排**：横向滚动卡片列表，每张图带标号（Ref 1, Ref 2...）、点击大图预览、独立删除与主参考图设为垫图参数；
- **API 兼容适配**：在调用 `/v1/images/generations` 时，若勾选垫图生成，将主参考图装载入 `payload.image / payload.init_image` 并根据提示词补充图生图权重。

### 3.3 画幅扩展与高级选项渐进展开
- **画幅扩展**：在原有 1:1, 16:9, 9:16, 4:3, 3:4 基础上，补充：
  - `21:9`（1792×768，电影宽银幕/横幅 Banner）；
  - `2:3`（768×1152，经典单反人像/海报构图）；
- **高级折叠面板**：
  - **质量档位 (Quality)**：`Auto`（默认）、`Standard`、`HD`；
  - **生成张数 (Count)**：`1` / `2` / `4` 单选药丸；
  - **负面提示词 (Negative Prompt)**：带一键清空与参数 `--no` 拼装。

### 3.4 产物反哺与以图生图闭环 (Result-to-Reference Flywheel)
- 每张成功生成的卡片底栏增加动作：「转为参考图 (Use as Reference)」；
- 点击后立即将生成的 Base64/Blob 推入多参考图托盘，并高亮反馈，用户可直接基于此图继续修改提示词、微调生图，实现 Infinite Canvas 式的渐进式探索。

### 3.5 「我的口袋」反推抽屉显式触发生命周期
- 抽屉顶部放置 `InlineModelPicker (capability="vision")`；
- 用户切换反推模型后，头部「重新反推」按钮高亮闪烁，显示「使用 [模型名称] 反推」；
- 避免模型切换期间发生静默并发请求；点击后调用该指定模型重新提取四维结构化积木，覆盖更新数据库 `PromptResult`。

## 4. 影响与收益评估 (Consequences)

### 正向影响 (Positive)
1. **交互层级大幅压平**：用户从“进设置 ➔ 找模型 ➔ 选模型 ➔ 保存 ➔ 回退 ➔ 执行”的 6 步繁琐链路，缩减为“胶囊一点一选即完成”的 1 步极简链路；
2. **BYOK 聚合场景完美支撑**：对于挂载几十个模型的中转 Key，直接就地拉取与搜索，解决选模型的燃眉之急；
3. **创作深度与可玩性跃升**：支持多图拖拽、剪贴板粘贴与生图结果图反哺参考图，真正构成了专业级图生图工作流闭环；
4. **与 Infinite Canvas 架构一致性**：汲取其最佳交互模式，使 Chrome 侧边栏在极小空间内爆发出媲美完整独立 Web 画布的专业生产力。

### 约束与防御 (Trade-offs & Mitigations)
- **侧边栏窄屏层级防遮挡**：Popover 浮层必须设置足够的 `z-index`（`z-50` 以上），并在视口边缘自动对齐；
- **非标准生图 API 垫图容错**：部分 OpenAI 中转仅支持纯文生图，若上传参考图返回 400/404 时，给出清晰的用户友好降级提示。
